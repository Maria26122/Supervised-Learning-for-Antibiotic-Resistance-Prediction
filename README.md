# Supervised-Learning-for-Antibiotic-Resistance-Prediction
## Overview

Supervised-Learning-for-Antibiotic-Resistance-Prediction is a project aimed at predicting antibiotic resistance using supervised learning techniques. This project leverages machine learning models to analyze and predict resistance patterns, aiding in effective treatment planning.

## Features

- **Model Evaluation**: Provides metrics such as accuracy, precision, recall, and F1 score to evaluate the performance of the model.
- **Model Attributes**:Logisctic Regression is used .

## Getting Started

### Prerequisites

- Python 3.x
- Flask

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Maria26122/Supervised-Learning-for-Antibiotic-Resistance-Prediction
   ```
2. Navigate to the project directory:
   ```bash
   cd Supervised-Learning-for-Antibiotic-Resistance-Prediction
   ```
3. Install the required packages:
   ```bash
   pip install -r requirements.ipynb
   ```

## Usage

1. Run the Flask application:
   ```bash
   python app.py
   ```
2. Access the API endpoints:
   - Get model evaluation metrics: `http://localhost:5000/model/evaluation`
   - Get model attributes: `http://localhost:5000/model/attributes`
